# 0. Быстрый старт: первый бот за 10 минут

Прежде чем разбираться в теории — соберём работающего бота. Это займёт минут десять, и после этого главы про Update, polling и Dispatcher будут читаться гораздо легче: у вас уже будет с чем сопоставлять.

Не переживайте, если что-то покажется непонятным. Всё, что мы сейчас напишем, подробно разберём в следующих главах. Пока важна одна вещь — **увидеть, что бот работает**.

## Что понадобится

- **Python 3.10 или новее.** Рекомендую 3.12 — с ним меньше сюрпризов с зависимостями. Проверить версию:

  ```bash
  python --version
  ```

- **pip** — обычно идёт в комплекте с Python.
- **Терминал.** На Windows подойдёт PowerShell или Git Bash, на macOS и Linux — любой.
- **Аккаунт Telegram.** Если у вас его нет — регистрируйтесь, без него бота не создать.
- **10–15 минут времени.**

Всё остальное установим по ходу дела.

## Шаг 1. Создаём проект и виртуальное окружение

Создайте папку для бота и перейдите в неё:

```bash
mkdir mybot
cd mybot
```

Затем создайте виртуальное окружение. Оно изолирует зависимости проекта от системного Python — это стандарт, и лучше привыкнуть к нему с самого начала.

```bash
python -m venv .venv
```

Активируйте его:

- **macOS / Linux:**

  ```bash
  source .venv/bin/activate
  ```

- **Windows (PowerShell):**

  ```powershell
  .venv\Scripts\Activate.ps1
  ```

- **Windows (cmd):**

  ```cmd
  .venv\Scripts\activate.bat
  ```

После активации в начале строки терминала появится `(.venv)`. Это значит, что вы внутри окружения.

## Шаг 2. Устанавливаем зависимости

```bash
pip install aiogram python-dotenv
```

- **aiogram** — фреймворк для Telegram-ботов. Мы будем использовать версию 3.x.
- **python-dotenv** — утилита, которая читает переменные окружения из файла `.env`.

Чуть позже мы заменим `python-dotenv` на `pydantic-settings` для более серьёзных проектов, но для первого бота и так сойдёт.

## Шаг 3. Получаем токен у @BotFather

Токен — это пароль от вашего бота. Получить его можно только у официального бота **@BotFather**.

1. Откройте Telegram и найдите `@BotFather` (у него синяя галочка).
2. Отправьте команду `/newbot`.
3. BotFather спросит **имя бота** — это то, что будут видеть пользователи. Например, `Мой Первый Бот`.
4. Затем спросит **username** — он должен заканчиваться на `bot`. Например, `my_first_test_bot`. Если username занят — придумайте другой.
5. В ответ BotFather пришлёт токен — длинную строку вида:

   ```
   123456789:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw
   ```

**Скопируйте его и сохраните.** Он понадобится нам на следующем шаге.

> **Важно:** токен — это ключ доступа к боту. Любой, кто его знает, может действовать от имени вашего бота. Никогда не публикуйте токен, не отправляйте его в чаты и не коммитьте в Git. Если токен утёк — немедленно отзовите его через `/revoke` в BotFather.

## Шаг 4. Складываем секреты в `.env`

Создайте в корне проекта файл `.env`:

```env
BOT_TOKEN=123456789:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw
```

Замените значение на ваш реальный токен.

Теперь создайте `.gitignore`, чтобы секреты и мусор не попали в репозиторий:

```gitignore
.env
.venv/
__pycache__/
*.pyc
```

Даже если вы не собираетесь выкладывать код на GitHub — заведите `.gitignore` сразу. Это привычка, которая однажды спасёт вас от утечки токена.

## Шаг 5. Пишем минимального бота

Создайте файл `bot.py`:

```python
import asyncio
import logging
import os

from dotenv import load_dotenv
from aiogram import Bot, Dispatcher, F
from aiogram.filters import CommandStart
from aiogram.types import Message

load_dotenv()
BOT_TOKEN = os.getenv("BOT_TOKEN")

dp = Dispatcher()


@dp.message(CommandStart())
async def cmd_start(message: Message):
    await message.answer("Привет! Я эхо-бот. Напиши что-нибудь.")


@dp.message(F.text)
async def echo(message: Message):
    await message.answer(f"Ты написал: {message.text}")


async def main():
    logging.basicConfig(level=logging.INFO)

    bot = Bot(token=BOT_TOKEN)
    await dp.start_polling(bot)


if __name__ == "__main__":
    asyncio.run(main())
```

Пока не разбирайтесь, что здесь к чему. Пробежимся по смыслу:

- Мы читаем токен из `.env` через `load_dotenv()` и `os.getenv()`.
- Создаём **Dispatcher** — объект, который будет решать, какой хендлер вызвать на каждое событие.
- Регистрируем два хендлера: один на команду `/start`, второй — на любое текстовое сообщение.
- В `main()` создаём бота и запускаем бесконечный цикл получения сообщений — `start_polling()`.

## Шаг 6. Запускаем

Убедитесь, что виртуальное окружение активировано, и запустите:

```bash
python bot.py
```

Если всё хорошо, в терминале появятся строки вида:

```
INFO:aiogram.dispatcher:Start polling
INFO:aiogram.dispatcher:Run polling for bot @my_first_test_bot id=123456789
```

Это значит, что бот подключился к Telegram и ждёт сообщений.

## Шаг 7. Проверяем

1. Откройте Telegram.
2. Найдите своего бота по username (тому, что заканчивается на `bot`).
3. Нажмите **Start** или отправьте `/start`.
4. Бот должен ответить: «Привет! Я эхо-бот. Напиши что-нибудь.»
5. Напишите любое сообщение — бот повторит его с приставкой «Ты написал:».

Поздравляю, у вас работает Telegram-бот.

Чтобы остановить — вернитесь в терминал и нажмите `Ctrl+C`.

## Если что-то не работает

Собрал здесь проблемы, с которыми сталкивается почти каждый новичок.

**`ModuleNotFoundError: No module named 'aiogram'`**

Скорее всего, не активировано виртуальное окружение. Проверьте, что в начале строки терминала есть `(.venv)`. Если нет — активируйте (шаг 1) и попробуйте снова.

**`pydantic_core._pydantic_core.ValidationError` или что-то похожее на старте**

Проверьте `.env`:

- Файл лежит в корне проекта, рядом с `bot.py`.
- Строка `BOT_TOKEN=...` без пробелов и кавычек.
- Токен скопирован полностью, ничего не потерялось.

**`aiogram.exceptions.TelegramUnauthorizedError: Unauthorized`**

Токен неверный или отозван. Сходите к BotFather, проверьте, что токен актуальный. Если сомневаетесь — выпустите новый командой `/revoke`.

**Бот запускается, но не отвечает**

Проверьте, что:

- Процесс `python bot.py` действительно работает (терминал занят, ничего не завершилось с ошибкой).
- В логах `INFO:aiogram.dispatcher:Start polling` появилось.
- Вы пишете **вашему** боту, а не другому с похожим username.

**`Conflict: terminated by other getUpdates request`**

Кто-то уже запустил этого бота — либо у вас открыт второй терминал с `python bot.py`, либо бот работает на другом компьютере. Telegram не даёт двум процессам одновременно забирать обновления. Остановите лишний процесс.

**Пишет на русском всё, что я ввожу, но сам не отвечает**

Скорее всего, `start_polling()` не запустился или упал раньше. Смотрите в логи — там будет traceback.

## Совет

Не бросайте проект сразу после первого запуска. Попробуйте:

- добавить команду `/help` и проверить, что она работает;
- поменять приветствие в `/start`;
- сделать хендлер, который считает длину сообщения и отвечает `len(text)`.

Такие микро-упражнения закрепляют базу лучше, чем чтение. А когда появится понимание — можно идти в главу 1 и разбираться, как всё это работает под капотом.
