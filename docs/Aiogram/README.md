Полный курс по созданию Telegram-ботов на Python с использованием aiogram. Материал построен так, чтобы сначала объяснить теорию, а потом показать, как она применяется на практике.

## О чём это руководство

Многие туториалы начинаются со слов «напишите вот этот код», и человек копирует его, не понимая, что происходит. Здесь другой подход: сначала разбираемся, как устроен Telegram Bot API и asyncio, потом — как aiogram ложится на эту основу, и только затем пишем код.

## Как читать

Файлы идут в логическом порядке: от того, как бот общается с Telegram, до того, как его выложить в облако. Если вы уже знакомы с asyncio, можно пропустить вторую главу. Всё остальное читайте по порядку — главы ссылаются друг на друга.

## Для кого это

Для тех, кто знает Python на уровне функций, классов и импортов, но никогда не писал асинхронный код и не работал с Telegram API. Опыт с другими ботами не требуется.
